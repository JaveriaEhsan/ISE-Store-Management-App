# Superstore App - 3rd Semester ISE Project at FAST

A standalone C++ desktop application for a small store to manage inventory
and record sales with minimal typing. Cashiers scan barcodes to get product
info and generate bills. Managers generate barcodes for products.

## Increment 1: Barcode Generator and Reader

## Features

**Generate Barcode**
- Input: a 6-digit number (first digit must not be 0)
- Output: a barcode shown on screen and saved as an image (filename chosen be user)

**Scan and decode barcode**
- Input: a barcode image generated by Part 1
- Output: the 6-digit number shown on screen

**Scan barcode with camera**
- Input: live camera preview; press SPACE to capture a picture
- Output: the decoded 6-digit number shown on screen
- The captured picture is saved temporarily, decoded, then deleted.

The barcode table, encoder, and decoder are written by us.
OpenCV is used only for image loading, drawing, showing, and saving.

## How the Barcode Works
- Each digit has a 7-bit pattern (1 = black bar, 0 = white bar).
- Barcode = start marker (101) + 6 digit patterns + end marker (101).
- Total length: 3 + (6 x 7) + 3 = 48 bits.

## Requirements
- C++17 compiler
- OpenCV 4.12.0
- CMake 3.26.4 and Visual Studio 2022
- A working webcam (only for camera scanning)

## Build and Run
```
cmake -B build
cmake --build build --config Release
build\Release\store_app.exe
```

## Usage
```
========== BARCODE SYSTEM ==========
1. Generate Barcode Image
2. Scan and Decode Barcode Image
3. Scan Barcode with Camera
4. Exit
```

**Filename rules**
- Must end with `.png`, `.jpg`, `.jpeg`, or `.bmp` (not case-sensitive).
- When generating, an existing file is never overwritten; choose a new name.

**Example**
1. Choose 1, enter `456789`, save as `code1.png`.
2. Choose 2, enter `code1.png`. Output: `Decoded number: 456789`.

**Camera scanning**
1. Generate a barcode with Option 1 and open the image full screen on a
   monitor or phone, or print it.
2. Choose 3. A camera window opens.
3. Hold the barcode flat and straight so it fills most of the frame, on a
   plain background, with no glare.
4. Click the camera window and press SPACE to capture, or ESC to cancel.

## Project Structure
```

|-- barcode/
|   |-- encoder.*     # number -> bits
|   |-- drawer.*      # bits -> console and image file
|   |-- reader.*      # image -> bits
|   |-- decoder.*     # bits -> number
|   |-- camera.*      # camera preview and capture
|-- CMakeLists.txt
```

## Testing
| Input | Expected result |
|-------|-----------------|
| `456789`, `a.png` | Barcode saved |
| `012345` | Rejected (first digit is 0) |
| `12345` or `abc` | Rejected (not 6 digits) |
| `fghj` or `.png` | Invalid filename |
| `a.png` again | File already exists |
| Scan `a.png` | `456789` |
| Scan `missing.png` | File not found |

## Known Limitations
- Camera scanning needs good lighting, a flat and straight barcode, and a
  plain background. Tilt, glare, and blur are not handled.
- Camera scanning works with the default camera (index 0) on Windows.
