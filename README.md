# Superstore App - 3rd Semester ISE Project at FAST

A standalone C++ desktop application for a small store to manage inventory
and record sales with minimal typing. Cashiers scan barcodes to get product
info and generate bills. Managers generate barcodes for products.

## Increment 1: Barcode Generator and Reader

**Part 1: Generate**
- Input: a 6-digit number (first digit must not be 0)
- Output: a barcode shown on screen and saved as an image (`barcode.png`)

**Part 2: Read**
- Input: a barcode image generated by Part 1
- Output: the 6-digit number shown on screen

The barcode table, encoder, and decoder are written by us.
OpenCV is used only for image loading, drawing, showing, and saving.

## How the Barcode Works
- Each digit has a 7-bit pattern (1 = black bar, 0 = white bar).
- Barcode = start marker (101) + 6 digit patterns + end marker (101).
